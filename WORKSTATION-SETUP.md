# Перенос GV2 на новую рабочую станцию

Файл для того, кто поднимает проект на новой машине — человека или AI-сессии,
у которой нет накопленного контекста. Он не заменяет [`AGENTS.md`](AGENTS.md) и
[`Docs/README.md`](Docs/README.md), а говорит, что нужно сделать до того, как их
читать, и чего на новой машине не окажется.

Зафиксировано на ревизии `f52a485` (2026-09-21). Если числа ниже не сходятся, а
ревизия ушла далеко вперёд — сначала проверьте, не устарел ли этот файл.

---

## 1. Что не приезжает вместе с репозиторием

Эти вещи живут вне каталога проекта и не попадают ни в архив, ни в клон.

**Unreal Engine 5.8.** `GV2.uproject` фиксирует `EngineAssociation: "5.8"`, и
`Tools/Testing/ue_test_report.py` сверяет это значение с тем, что движок сообщает
в рантайме: несовпадение версии завалит приёмку, а не просто предупредит.

Проект включает четыре плагина, два из них **экспериментальные**:

| Плагин | Зачем |
|---|---|
| `ModelContextProtocol` | Поднимает MCP на порту 8000 — без него нельзя править `.uasset` |
| `AllToolsets` | Требуется проектом |
| `ModelingToolsEditorMode`, `CommonUI` | Штатные |

Все четыре штатно лежат в `Engine/Plugins/`, но экспериментальные иногда вырезают
при сборке движка — проверьте, что они на месте, до первого запуска редактора.

**Память проекта Claude** — каталог `~/.claude/projects/<путь-проекта>/`, внутри
`memory/` с `MEMORY.md` и файлами накопленного контекста (на момент записи — 10
файлов, ~289 МБ вместе с историей сессий).

Имя каталога кодирует путь к проекту: `-home-king-ue5-GV2` для `/home/king/ue5/GV2`.
**Если проект ляжет по другому пути или под другим пользователем — каталог нужно
переименовать под новый путь**, иначе память не подхватится и сессия начнёт с нуля.

**Авторизация `gh`** — в keyring, не переносится. `gh auth login`.

**Git identity** — если `user.name`/`user.email` были только в глобальном конфиге.

**Опционально:** `~/.config/Epic/UnrealEngine/` — раскладка и настройки редактора.
Остальное в `~/.config/Epic` (около 850 МБ) — кэши и блокировки, регенерируются.

## 2. Что поставить

- **cmake**, **C++-компилятор**, **python3**. Проверено на cmake 4.4.3, GCC 16.2.1,
  Python 3.14.7.
- **Python-зависимостей нет.** Весь инструментарий на stdlib, `pip install` не нужен.
- Опционально: `pigz` (ускоряет `Tools/archive_project.sh`, без него gzip),
  `pytest` (нужен только чтобы прогнать 63 теста вендоренного `Tools/UECtl`).

## 3. Проверка, что переезд состоялся

Выполнять по порядку. Числа — ожидаемые на ревизии из шапки.

### 3.1 Репозиторий

```bash
git status            # чисто
git log --oneline -1  # сверить с ожидаемой ревизией
```

**Если переносили архивом, а не клоном** — убедитесь, что приехали все коммиты:
на момент записи их было 14 сверх `origin/main`. Архив включает `.git` целиком,
клон с origin — нет.

### 3.2 Портативный контур — движок не нужен

```bash
mkdir -p build/.cmake/api/v1/query && touch build/.cmake/api/v1/query/codemodel-v2
cmake -S . -B build
cmake --build build -j8
ctest --test-dir build
python3 Tools/Documentation/validate_docs.py
```

Ожидается: **CTest 135/135**, **validate_docs 195 файлов**.

Первая строка обязательна. Без неё конфигурация падает с
`Missing pre-configure CMake File API query` — гейт полноты codemodel требует
query-каталог до конфигурации, а не после.

### 3.3 Сборка и приёмка — нужен движок

```bash
$UE_ROOT/Engine/Build/BatchFiles/Linux/Build.sh GV2Editor Linux Development "$PWD/GV2.uproject" -WaitMutex -NoHotReloadFromIDE
python3 Tools/Testing/run_ue_acceptance.py --filter GV2 --fresh-process
```

Ожидается: UBT `Result: Succeeded`, приёмка **208/208**, `Source Diff: clean`.

Приёмка конфликтует с запущенным редактором — он держит те же `Binaries/` и
`Intermediate/`. Закройте редактор перед сборкой.

### 3.4 Editor API

Запустить редактор, затем:

```bash
python3 Tools/MCP/run_ue_tests.py --filter StartsWith:GV2
```

## 4. Переменные окружения

| Переменная | По умолчанию | Когда менять |
|---|---|---|
| `UE_ROOT` | `/opt/unreal-engine` | Движок установлен в другое место |
| `UNREAL_MCP_URL` | `http://127.0.0.1:8000/mcp` | Редактор не на этой машине |

Это единственные точки привязки к размещению движка и редактора. Значение по
умолчанию для `UE_ROOT` задано одной константой `DEFAULT_UE_ROOT` в каждом из двух
использующих файлов; менять литералы по дереву не нужно.

## 5. Правила, которые нарушают чаще всего

Полный свод — [`AGENTS.md`](AGENTS.md). Здесь то, что новая сессия нарушает, не
успев его прочитать:

- **`.uasset` правится только через Editor API** (`unreal-mcp`), никогда прямой
  записью бинарного файла. Недоступность редактора исключения не создаёт.
- **Запущенный пользователем Unreal Editor нельзя завершать** (`kill`, `killall`)
  без явного указания — каждый раз отдельно.
- **Коммитить только файлы своей задачи.** В дереве бывает работа параллельной
  сессии; `git add -A` её захватит.
- **Не пушить без явной просьбы.** Не переписывать историю (`amend`, `rebase`,
  `reset`) без явной просьбы.
- **Отвечать по-русски** в этом проекте.

## 7. Перенос в обратную сторону

`bash Tools/archive_project.sh` собирает переносимый архив (~21 МБ): исключает
сборочные кэши и агентские worktree, сохраняет `.git` с историей. `--dry-run`
покажет состав без создания архива.

Оценка объёма в `--dry-run` считается `du` и совпадает с фактическим содержимым
архива не точно: авторитетен обход `tar`, а не эта оценка.
