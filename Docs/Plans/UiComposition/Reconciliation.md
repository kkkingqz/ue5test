# M2 — Reconciliation

> **Материализует:** разделы «Game Shell», «Reconciliation» и «Route/layer rules» [UI Document](../../UI/UIDocumentAndReconciliation.md).
> **Задачи:** UIC-06…11.
> **Результат:** маршрут, оверлеи и модалки существуют одновременно; перестраивается только изменившееся.

## Результат этапа

`UGV2RuntimeSubsystem` перестаёт быть держателем единственного активного экрана. Lua публикует полный документ со слоями, Presentation сопоставляет экземпляры по `layer + instance_key` и переиспользует виджеты.

Этот этап закрывает первый пункт ближайших пробелов из [Implementation Status](../../Status/ImplementationStatus.md).

## Задачи

- [ ] **UIC-06 — Слои Game Shell**
  - Зависимости: UIC-01.
  - `FGV2ScreenRegistryEntry.Layer` существует со значением по умолчанию `location_content`, но хостов слоёв нет.
  - Done: `WBP_GameShell` содержит именованные хосты `background`, `location_content`, `character_presentation`, `core_interface`, `overlay_stack`, `modal_stack`; реестр отклоняет запись с неизвестным слоем; ассеты изменены через `unreal-mcp` с последующим compile и save; порядок отрисовки слоёв зафиксирован в contract.
  - Evidence: `Content/UI/Shell/WBP_GameShell.uasset`, `Source/GV2/Private/UI/GV2ScreenRegistry.cpp`, `GV2.Runtime.Presentation.ScreenRegistry*`.

- [ ] **UIC-07 — Конверт документа в Lua**
  - Зависимости: UIC-06.
  - Сегодня источник презентации разрешает один активный экран.
  - Done: источник презентации возвращает конверт `{ ui_instance_id, revision, route, overlays, modals }`; `revision` монотонна внутри экземпляра; более одного маршрута — типизированный отказ; авторский слой получает способ объявить оверлей и модалку без ручной сборки конверта; открытость оверлея и модалки хранится в состоянии вне сейва; правила покрыты спеками.
  - Evidence: `Scripts/runtime/`, `Scripts/authoring/`, `Tests/Lua/`.

- [ ] **UIC-08 — Сопоставление экземпляров**
  - Зависимости: UIC-07.
  - Done: reconciler сопоставляет Screen Instances по паре `layer + instance_key`; совпадение идентичности и `screen_id` переиспользует виджет и применяет полный набор полей; смена `screen_id` заменяет класс через реестр; исчезнувший экземпляр логически отключается до анимации выхода; automation подтверждает, что ревизия, меняющая один экземпляр, не пересоздаёт остальные.
  - Evidence: `Source/GV2/Private/UI/`, `GV2.Runtime.Presentation.*`.

- [ ] **UIC-09 — Поэлементная реконсиляция полей**
  - Зависимости: UIC-08, UIC-03.
  - Done: внутри повторяемого поля элементы сопоставляются по паре «тип + `key`» согласно таблице решений из [UI Document](../../UI/UIDocumentAndReconciliation.md); изменение порядка при неизменном наборе ключей выполняется переупорядочиванием без пересоздания; UI-local состояние переиспользованного элемента сохраняется; handle удалённого элемента инвалидируется до анимации выхода.
  - Evidence: `Source/GV2/Private/UI/`, `GV2.Runtime.Presentation.*`.

- [ ] **UIC-10 — Правила слоёв**
  - Зависимости: UIC-08.
  - Done: модалка блокирует нижние слои, интерактивна только верхняя пригодная; оверлей по умолчанию маршрут не блокирует; удаление владельца каскадно удаляет его модалки; неизвестный `screen_id`, несовместимый класс реестра и несовместимый контракт поля делают документ невалидным до интерактивного apply.
  - Evidence: `Source/GV2/Private/UI/`, `GV2.Runtime.Presentation.*`.

- [ ] **UIC-11 — Атомарность и переход `rh` на слои**
  - Зависимости: UIC-09, UIC-10.
  - Done: отказ любого кандидата оставляет предыдущую ревизию и её handles без изменений, частично обновлённого интерактивного экрана не возникает; публикация binding set остаётся атомарной; экраны `rh` переведены на конверт со слоями, а покупка использует модалку подтверждения; изменение `final_screen_fields` в golden воспроизведено манифестом и объяснено в change set; полный `ctest`, `gv2-headless --self-test`, `--check-scripts` и Unreal automation зелёные.
  - Evidence: `GameData/rh/scripts/`, golden-прогон, отчёт CTest.

## Проверка milestone

- [ ] Маршрут, оверлей и модалка существуют одновременно.
- [ ] Модалка блокирует нижние слои; удаление владельца каскадно удаляет её.
- [ ] Ревизия, меняющая одно поле, не пересоздаёт остальные экземпляры и элементы.
- [ ] Изменение порядка элементов не пересоздаёт ни одного виджета.
- [ ] Отказ кандидата не оставляет частично обновлённого экрана.
- [ ] Загрузка сейва возвращает маршрут; стек оверлеев пуст.
