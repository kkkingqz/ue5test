# M3 — Tabs

> **Материализует:** раздел 5 [UI Composition and Scaling](../../Proposals/UiCompositionAndScalingProposal.md).
> **Задачи:** UIC-12…17.
> **Результат:** Screen Instance становится рекурсивным; вкладка переключается без участия геймплея.

## Результат этапа

Вкладка — вложенный Screen Instance, а не новый вид поля. Переключение вкладки не порождает команду, не меняет ревизию документа и не попадает в сейв.

Содержимое всех вкладок присутствует в документе одновременно — это прямое следствие UI-local природы активной вкладки. Поэтому интерактивность неактивных вкладок является отдельной задачей, а не деталью реализации.

## Задачи

- [ ] **UIC-12 — Слой `embedded` в реестре**
  - Зависимости: UIC-06.
  - Done: запись реестра со слоем `embedded` может быть только вложенным содержимым; попытка использовать её как маршрут, оверлей или модалку — ошибка валидации реестра, а не рантайма; обратное ограничение симметрично; набор вкладок внутри набора вкладок отклоняется валидацией документа.
  - Evidence: `Source/GV2/Private/UI/GV2ScreenRegistry.cpp`, `GV2.Runtime.Presentation.ScreenRegistry*`.

- [ ] **UIC-13 — Схема набора вкладок**
  - Зависимости: UIC-12.
  - Done: `core:schema.ui_field.tab_set.v1` описана в [Screen Templates](../../UI/ScreenTemplates.md) наравне с пятью существующими; значение содержит `default_tab_key` и упорядоченный список вкладок с `key`, `title` в форме `TextSpec`, `screen_id` и полным набором полей; `WBP_TabSet` и `UGV2TabSetWidgetBase` созданы через `unreal-mcp`, наследуют утверждённые leaf-адаптеры и не создают параллельных путей для текста и повторяемых элементов; сырая строка в заголовке вкладки отклоняется.
  - Evidence: `Docs/UI/ScreenTemplates.md`, `Content/UI/Widgets/WBP_TabSet.uasset`, `Source/GV2/Private/UI/`.

- [ ] **UIC-14 — Рекурсивный apply**
  - Зависимости: UIC-13, UIC-09.
  - Done: адаптер набора вкладок разрешает вложенный `screen_id` через тот же Screen Registry и применяет его поля тем же `ApplyScreenFields`; `node_key_path` удлиняется путём вкладки, binding registry не меняется; реконсиляция вкладок использует правило ключей M1, где `key` вкладки является её `instance_key`; отказ вложенного экземпляра отклоняет документ целиком.
  - Evidence: `Source/GV2/Private/UI/`, `GV2.Runtime.Presentation.*`.

- [ ] **UIC-15 — Активная вкладка как UI-local состояние**
  - Зависимости: UIC-14.
  - Done: активная вкладка хранится в UE по паре «путь экземпляра экрана + `field_id`»; начальное значение — `default_tab_key`, при его отсутствии первая вкладка; реконсиляция, сохраняющая экземпляр, сохраняет активную вкладку; исчезновение активной вкладки возвращает к `default_tab_key`, затем к первой; уничтожение экземпляра теряет состояние; в сейв оно не попадает и в дайджест не входит.
  - Evidence: `Source/GV2/Private/UI/`, `GV2.Runtime.Presentation.*`.

- [ ] **UIC-16 — Интерактивна только активная вкладка**
  - Зависимости: UIC-15.
  - Done: binding records создаются для всех вкладок, но Semantic Input принимает handle только активной вкладки и отклоняет остальные так же, как stale; переключение вкладки меняет множество интерактивных handles, не меняя ревизию документа; правило и его причина записаны в [Semantic Input](../../UI/SemanticInput.md); отрицательный случай покрыт automation.
  - Evidence: `Docs/UI/SemanticInput.md`, `Source/GV2/Private/UI/`, `GV2.Runtime.Presentation.*`.

- [ ] **UIC-17 — Вкладки в авторском слое и в `rh`**
  - Зависимости: UIC-16.
  - Done: авторский слой объявляет набор вкладок без ручной сборки конверта и выводит ключи по правилу UIC-04; экран `rh` использует вкладки на реальном содержимом; сохранение и загрузка возвращают маршрут с начальной активной вкладкой; изменение `final_screen_fields` в golden воспроизведено манифестом; полный `ctest`, `gv2-headless --self-test`, `--check-scripts` и Unreal automation зелёные.
  - Evidence: `Scripts/authoring/`, `GameData/rh/`, `Tests/Lua/`, отчёт CTest.

## Проверка milestone

- [ ] Переключение вкладки не порождает команду и не меняет ревизию документа.
- [ ] Handle неактивной вкладки отклоняется Semantic Input.
- [ ] Активная вкладка не попадает в сейв и в дайджест.
- [ ] Экран `embedded` не может быть маршрутом; маршрут не может быть содержимым вкладки.
- [ ] Набор вкладок внутри набора вкладок отклоняется.
