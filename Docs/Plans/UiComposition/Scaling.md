# M4 — Scaling

> **Материализует:** раздел 6 [UI Composition and Scaling](../../Proposals/UiCompositionAndScalingProposal.md).
> **Задачи:** UIC-18…22.
> **Результат:** одно правило масштаба и два числа вместо ненаписанного поведения при смене разрешения.

## Результат этапа

Художник получает разрешение, под которое рисует. Раскладка на любом поддерживаемом экране отличается только масштабом и шириной фона. Поведение блока при растягивании перестаёт быть решением верстальщика и становится следствием выбранного ресурса.

Этап не зависит от M1…M3.

## Задачи

- [ ] **UIC-18 — Разрешение авторинга и правило масштаба**
  - Зависимости: UIC-01.
  - Done: `1920 × 1080` зафиксировано как разрешение авторинга в одном месте как константа проекта и не повторяется в шаблонах; масштаб вычисляется как `min(viewport_height / 1080, viewport_width / 1440)`; колонка контента ограничена 1920 авторскими единицами и центрируется; contract содержит таблицу расчёта для проверяемых разрешений; размеры типографики темы выражены в авторских единицах.
  - Evidence: `Docs/UI/ScreenTemplates.md`, `Source/GV2/Private/UI/`, `Content/UI/Shell/WBP_GameShell.uasset`.

- [ ] **UIC-19 — Растягивание по режиму ресурса**
  - Зависимости: UIC-18.
  - `AcceptedRenderMode` и `FixedAspectRatio` существуют как правила отрисовки; правилами раскладки они не являются.
  - Done: [Image Resource Contract](../../UI/ImageResources.md) объявляет соответствие «режим ресурса → поведение блока»: `tile` свободно, `fixed_aspect` с сохранением пропорций, `nine_slice` с фиксированными углами; блок без фонового ресурса определяется шаблоном; ограничение слота выводится из объявленного режима, а не задаётся отдельно.
  - Evidence: `Docs/UI/ImageResources.md`, `Source/GV2/Private/UI/GV2ImagePresentation.cpp`.

- [ ] **UIC-20 — Гейт шаблонов**
  - Зависимости: UIC-19.
  - Done: существующая automation по полному инвентарю `/Game/UI` дополнена проверкой противоречия между объявленным режимом блока и ограничениями его слота; блок `fixed_aspect` в свободно растягивающемся по обеим осям слоте — ошибка; отрицательный случай воспроизводится на тестовом шаблоне и удаляется вместе с ним.
  - Evidence: `Source/GV2/Private/Tests/`, `GV2.Runtime.Presentation.*`.

- [ ] **UIC-21 — Фоновый слой**
  - Зависимости: UIC-19.
  - `fixed_aspect` не допускает ни crop, ни неравномерного растягивания, поэтому полноэкранная иллюстрация не может закрыть произвольные пропорции.
  - Done: слой `background` строится как `tile`-подложка, поверх которой опционально вписывается `fixed_aspect`-иллюстрация; полноэкранная иллюстрация без подложки — ошибка композиции, отклоняемая гейтом UIC-20; правило записано в contract.
  - Evidence: `Docs/UI/ImageResources.md`, `Content/UI/Shell/WBP_GameShell.uasset`.

- [ ] **UIC-22 — Проверка на разрешениях**
  - Зависимости: UIC-20, UIC-21.
  - Done: automation прогоняет зарегистрированные экраны на `1280×720`, `1920×1080`, `3840×2160`, `3440×1440` и `1024×768`; на каждом разрешении расчётный масштаб совпадает с таблицей contract, ни один элемент не выходит за границы видимой области и ни один блок `fixed_aspect` не меняет пропорций; безопасная область применяется как отступ Game Shell и boundary не пересекает.
  - Evidence: `Source/GV2/Private/Tests/`, `GV2.Runtime.Presentation.*`.

## Проверка milestone

- [ ] Разрешение авторинга задано в одном месте.
- [ ] На пяти проверяемых разрешениях раскладка отличается только масштабом и шириной фона.
- [ ] Блок `fixed_aspect` в свободно растягивающемся слоте отклоняется гейтом.
- [ ] Фон заполняет видимую область при любых пропорциях.
