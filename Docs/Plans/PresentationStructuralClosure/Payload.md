# M4 — Self-Contained Payload

> **Материализует:** `D3` [ADR-0043](../../ADR/0043-presentation-apply-boundary.md) и вторую половину `PAH-R1`.
> **Задачи:** PSC-09.
> **Результат:** подготовленная операция несёт разрешённое значение, а не ссылку, по которой его можно получить.

## Результат этапа

Этап идёт после границы модуля намеренно. Пока применению доступны типы авторитета, «нагрузка самодостаточна» проверяется дисциплиной: можно написать самодостаточную нагрузку и рядом оставить путь, по которому значение всё равно доразрешается. После `PSC-07` такого пути нет физически, и утверждение становится проверяемым тем, что код собирается.

`STATUS-012` закрыл этот принцип для ресурсов изображений: подготовка сохраняла идентификатор, применение резолвило заново. Задача распространяет его на все виды значений — и первым на текст, где та же форма живёт через тему.

## Задачи

- [ ] **PSC-09 — Каждый вид подготовленного значения несёт разрешённую нагрузку**
  - Зависимости: PSC-06, PSC-08.
  - Инвариант: подготовленная операция самодостаточна ([ADR-0043](../../ADR/0043-presentation-apply-boundary.md), `D3`). Нарушение выглядит безобидно, пока авторитет неизменен в пределах сессии: применяется значение, выведенное повторно, а не то, которое подготовка проверила. Ровно так жил `STATUS-012`, и ровно так живёт разрешение стиля текста.
  - Не считается закрытием: самодостаточность для тех видов, где она понадобилась по ходу, при сохранении остальных на идентификаторах; мягкая ссылка внутри нагрузки — она переносит разрешение на момент разыменования, то есть на применение; хранение в нагрузке указателя на контекст подготовки.
  - Done:
    - каждый вид подготовленного значения несёт разрешённую нагрузку, достаточную для применения; множество видов берётся обходом перечисления видов, а не перечнем в задаче;
    - разрешение стиля текста происходит в подготовке, и подготовленное текстовое значение несёт разрешённый класс стиля;
    - в составе публичной подготовленной нагрузки нет мягких ссылок и указателей на резолверы или контекст — это утверждает инвентаризация полей, выведенная из объявления, с отрицательным самотестом;
    - новый вид подготовленной операции без применения даёт ошибку компиляции — виды образуют одно исчерпывающее перечисление;
    - счётчик обращений к авторитетам показывает ноль вокруг применения для каждого вида значения, а не только для одного сценария;
    - отказ подготовки при неразрешимом значении сохраняется и типизирован — самодостаточность не превращает ошибку разрешения в тихое умолчание.
  - Evidence: `Source/GV2/Private/UI/GV2TextPipeline.cpp`, `Source/GV2/Private/UI/GV2PropertyConsumers.cpp`, `Source/GV2/Public/UI/GV2PreparedUiValue.h`, `Tools/Testing/`.

## Проверка milestone

- [ ] Ни один вид подготовленного значения не требует доразрешения при применении.
- [ ] В подготовленной нагрузке нет мягких ссылок и указателей на резолверы, и это утверждает инвентаризация по объявлению.
- [ ] Счётчик обращений даёт ноль вокруг применения для каждого вида, а не для одного.
- [ ] Неразрешимое значение по-прежнему даёт типизированный отказ подготовки.
