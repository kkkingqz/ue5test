# M3 — Transactional Commit

> **Материализует:** `REM-02` и сверку закрытий раунда.
> **Задачи:** GBH-09…11.
> **Результат:** утверждение об атомарности либо истинно для переиспользуемого живого экрана, либо сужено до фактического.

## Результат этапа

Это единственная настоящая архитектурная недоработка раунда. Остальные находки — незавершённые абстракции или отсутствующие проверки; здесь отсутствует возможность модели.

`CommitUiHostProperties` выполняет подготовленные мутации последовательно и выходит по первому отказу. Отката нет, предыдущее физическое состояние не хранится. Для свежего кандидата, созданного off-tree, это безопасно: частично изменённый виджет ещё не опубликован. Для **переиспользуемого экземпляра** цель — уже живая предыдущая ревизия, и отказ в середине оставляет логически старую ревизию с физически частично новым интерфейсом.

Контракт при этом утверждает атомарность без оговорок.

Отдельно фиксируется, почему это не было найдено раньше: `PCC-07` закрывался инъекцией отказа, и инъекция стояла на уровне экрана, а не в середине commit переиспользуемого экземпляра. Проверка доказала случай, который проверяла.

## Задачи

- [ ] **GBH-09 — Решение о механизме**
  - Выбор меняет модель, а не реализацию, поэтому принимается до кода.
  - Done: ADR фиксирует и обосновывает выбор одного из механизмов — откат каждой мутации с хранением предыдущего физического состояния, commit в теневое состояние с последующим свопом, иной транзакционный commit — либо мотивированное сужение контракта до фактического поведения с наблюдаемым условием пересмотра; рассмотрена стоимость каждого варианта для переиспользуемых экземпляров и для коллекций; решение учитывает, что подготовка уже работает off-tree, и объясняет, почему выбранный механизм согласуется с этим, а не дублирует его; при сужении контракта строка `STATUS-NNN` создаётся тем же change set.
  - Evidence: `Docs/ADR/`, `Docs/UI/UIDocumentAndReconciliation.md`.

- [ ] **GBH-10 — Реализация выбранного механизма**
  - Зависимости: GBH-09.
  - Done: механизм реализован для всех путей, где цель commit может быть живым переиспользуемым виджетом, включая элементы коллекций и вложенные экраны; отказ в середине commit не оставляет наблюдаемых следов новой ревизии на предыдущей; если выбрано сужение контракта — нормативный текст описывает фактическое поведение, а параллельного механизма не появляется; поведение подтверждено на переиспользуемом экземпляре, а не только на свежем.
  - Evidence: `Source/GV2/Private/UI/GV2UiMutationPlan.cpp`, `Source/GV2/Private/UI/GV2ScreenWidgetBase.cpp`, `Source/GV2/Private/UI/GV2LayeredUiReconciler.cpp`.

- [ ] **GBH-11 — Инъекция в опасную точку и сверка закрытий**
  - Зависимости: GBH-10.
  - Done: инъекция отказа поставлена **в середину commit переиспользуемого живого экземпляра** и проверяет состояние предыдущей ревизии, а не возвращённое значение; отдельно проверено, что существующая инъекция уровня экрана эту точку не покрывает — то есть новый тест краснеет там, где старый зелёный; для каждой находки `REM-01`…`REM-07` названа проверка и продемонстрировано, что она краснеет при откате соответствующего изменения; подтверждено, что закрыт класс, а не экземпляр: закрытие, тронувшее несколько мест одной формы, покрывает все либо объясняет исключения; ревью переносится в `Docs/Status/Archive/` по процедуре `AGENTS.md`.
  - Evidence: отчёт change set, `Source/GV2/Private/Tests/`, `Docs/Status/Archive/`.
