# M2 — Composites

> **Материализует:** разделы 3, 5—12 [предложения](../../Proposals/GameplayLocationScreenProposal.md).
> **Задачи:** GLS-05…09.
> **Результат:** четыре композита и шаблон существуют в слое `textsystem` и собраны из примитивов `core`.

## Результат этапа

Появляется физический экран. Ни один ассет этапа не попадает в `Content/UI/` или `Content/RH/UI/`: верхняя панель, панель состояния, сцена и панель команд — основа любой текстовой RPG, а [UI Index](../../UI/README.md) уже относит шаблон экрана локации к `textsystem`.

## Задачи

- [x] **GLS-05 — Верхняя панель**
  - Зависимости: GLS-03.
  - Done: композит показывает день, текущую локацию, основной ресурс и индикаторы; собран из `Panel`, `Text`, `Icon` и `Separator`; предпочтительная высота выводится из типографики и ограничена min/max, а не задана долей экрана; полной карточкой персонажа не становится — набор полей ограничен схемой.
  - Evidence: `Content/TextSystem/UI/Widgets/`, `Source/GV2/Private/UI/`.

- [x] **GLS-06 — Панель состояния персонажа**
  - Зависимости: GLS-03.
  - Done: композит показывает портрет, имя, показатели, активные предметы и эффекты; собран из `Panel`, `Portrait`, `Text`, `ProgressBar` и списка иконок; предметы и эффекты остаются разными наборами и в один игровой концепт не объединяются; предпочтительная ширина ограничена min/max; подсказки для иконок не вводятся.
  - Evidence: `Content/TextSystem/UI/Widgets/`.

- [x] **GLS-07 — Сцена**
  - Зависимости: GLS-03.
  - Done: композит состоит из слоя подложки, слоя фоновой иллюстрации, слоя персонажа и необязательного слоя контекстного текста; подложка `tile` заполняет прямоугольник сцены при любых пропорциях, иллюстрация вписывается с сохранением пропорций без обрезки; персонаж вписывается и привязан к нижнему краю; слой персонажа спроектирован как коллекция для будущих нескольких персонажей, но в этом срезе показывает одного; произвольного графа сцены не вводится.
  - Evidence: `Content/TextSystem/UI/Widgets/`.

- [x] **GLS-08 — Панель команд**
  - Зависимости: GLS-03.
  - Done: композит строит кнопки списком через общий механизм повторения, а не фиксированным набором; каждая кнопка несёт подпись, необязательную иконку, признак доступности и привязку семантического действия; при нехватке ширины кнопки переносятся на следующую строку, а не уменьшаются ниже читаемого размера; нажатие отправляет семантическое действие и игровой логики не выполняет.
  - Evidence: `Content/TextSystem/UI/Widgets/`.

- [x] **GLS-09 — Шаблон экрана**
  - Зависимости: GLS-05, GLS-06, GLS-07, GLS-08.
  - Done: шаблон собирает четыре композита; распределение места задано preferred-размерами с ограничениями min/max, сцена занимает остаток; доли экрана в процентах используются только как ориентир на опорном разрешении; automation по полному инвентарю `/Game/UI` подтверждает, что ни один композит не создал собственного пути для текста, изображения или повторяемых детей.
  - Evidence: `Content/TextSystem/UI/Widgets/`, `Source/GV2/Private/Tests/`.

## Проверка milestone

- [x] Все пять ассетов лежат в `Content/TextSystem/UI/`.
- [x] В `Content/RH/UI/` нет ни одного ассета.
- [x] Ни один композит не обходит конвейеры текста и изображений.
- [x] Команды переносятся, а не уменьшаются.
- [x] Фон не обрезается и не искажается.
