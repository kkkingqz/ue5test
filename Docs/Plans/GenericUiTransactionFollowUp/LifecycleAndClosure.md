# M3 — Lifecycle and Closure

> **Материализует:** `GBH-R5`, перечислитель границ отката и закрытие раунда.
> **Задачи:** GBF-06…08.
> **Результат:** побочные эффекты вынесены за пределы отменяемой транзакции, а множество границ перестаёт быть рукописным.

## Результат этапа

`GBF-07` — самая важная задача плана, и её легко принять за формальный аудит. `GBH-10` нашёл шесть границ отката систематическим просмотром каждой последовательности фазы Commit. Список был верен в момент написания; седьмую границу, добавленную позже, он не покроет, и обнаружит её следующее внешнее ревью — ровно так, как обнаружило `GBH-R1`, где рукописный перечень ветвей отказа attach не содержал `AddChild`.

Поэтому задача считается закрытой не тогда, когда границы перечислены, а когда **перечисление выполняет механизм**.

## Задачи

- [ ] **GBF-06 — Callback вне отменяемой транзакции**
  - Зависимости: GBF-05.
  - `OnScreenFieldsApplied` вызывается до окончательной публикации транзакции документа. Blueprint, подписанный на это событие, наблюдает и может изменить состояние ревизии, которая ещё может быть отменена, — и его собственные действия откатом не покрываются.
  - Done: ни один Blueprint/UI-callback не исполняется внутри отменяемой транзакции, если сам не является её частью; `OnScreenFieldsApplied` либо перенесён за точку окончательной публикации, либо удалён, если подписчиков нет — выбор обоснован проверкой фактических подписчиков в C++ **и во всех** `.uasset`, а не в трёх известных; тест подтверждает, что при отказе после точки, где callback раньше вызывался, он не вызывается вовсе; контракт описывает фактический момент вызова.
  - Evidence: `Source/GV2/Private/UI/GV2ScreenWidgetBase.cpp`, `Content/`, `Docs/UI/UIDocumentAndReconciliation.md`.

- [ ] **GBF-07 — Границы отката перечисляет механизм**
  - Зависимости: GBF-06.
  - Шесть границ (свойство, хост/экран, документ, Shell-attach, элемент keyed-коллекции, вложенный экран во вкладке) найдены аудитом. Рукописный список — напоминание, а не гейт: он верен на момент написания и молча устаревает.
  - Done: введён механизм, перечисляющий места, где может произойти отказ после начала применения, и требующий для каждого либо покрытия контрактом восстановления, либо явной классификации с причиной; появление новой такой границы без покрытия краснит сборку; шесть известных границ проходят через этот механизм, а не перечисляются рядом с ним; **отрицательный самотест** — синтетическая новая граница без покрытия обязана его уронить; в отчёте зафиксировано, что именно механизм перечисляет и какие места он по построению не видит.
  - Evidence: `Source/GV2/Private/UI/`, `Source/GV2/Private/Tests/`, отчёт change set.

- [ ] **GBF-08 — Сверка закрытий и архивация раунда**
  - Зависимости: GBF-07.
  - Done: для каждой находки `GBH-R1`…`GBH-R7` назван гейт и **продемонстрировано**, что он краснеет при откате соответствующего изменения; подтверждено, что закрыт класс, а не экземпляр: закрытие, тронувшее несколько мест одной формы, покрывает все либо объясняет исключения; отдельно проверено, что ни одна починка не свелась к сужению `ADR-0041` и не ввела schema-specific путь; `STATUS-008` не изменён, условие его повторного открытия не наступило; полный прогон — UE automation, портативный CTest, `gv2-headless --check-scripts`, `validate_docs.py` — зелёный; ревью перенесено в `Docs/Status/Archive/` двухкоммитной процедурой `AGENTS.md`.
  - Evidence: отчёт change set, `Source/GV2/Private/Tests/`, `Docs/Status/Archive/`.

## Проверка milestone

- [ ] Ни один callback не наблюдает состояние, которое может быть отменено.
- [ ] Новая граница отката без покрытия невозможна, и отрицательный самотест это подтверждает.
- [ ] Каждая находка раунда закрыта продемонстрированным red-on-revert гейтом.
- [ ] Записано, какие места механизм перечисления по построению не видит.
