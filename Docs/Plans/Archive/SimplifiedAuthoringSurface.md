# SimplifiedAuthoringSurface: итог выполнения

> **Состояние:** план выполнен; документ является историческим summary, а не источником правил или задач.

## Цель и результат

**Цель:** Убрать из designer-facing Lua всё, что обслуживает интеграцию с GV2, а не описывает игру: префикс `M.`, ручной манифест, конверты результата, разбор транспортного DTO, обновление интерфейса, дублирующий сервис

**Результат:** геймплей `rh` — один файл правил игры без обвязки; инфраструктурных Lua-файлов в пакете не остаётся

## Этапы и задачи

### M1 — Authoring Environment

файл правил игры содержит только правила игры

- `SAS-01` — Создать ADR по окружению authoring-скрипта
- `SAS-02` — Класс authoring-скриптов и их окружение
- `SAS-03` — Дескриптор создаётся загрузчиком
- `SAS-04` — Неявный успех команды
- `SAS-05` — Спеки через диспетчеризацию и синхронизация contract

### M2 — Module Discovery

добавление файла не требует правки другого файла

- `SAS-06` — Детерминированное обнаружение и генерируемый манифест
- `SAS-07` — Правила идентичности модуля
- `SAS-08` — Зависимости из литеральных `require`
- `SAS-09` — Редкие метаданные и синхронизация contract

### M3 — Domain API

правило игры выражается предусловием и операцией, без разбора результатов и транспорта

- `SAS-10` — Предусловия `require_*`
- `SAS-11` — Операции `spend_*` без разбора результата
- `SAS-12` — Обработчик получает объекты
- `SAS-13` — Единый доменный API актора

### M4 — Presentation Source

геймплей не знает про интерфейс; экран обновляется сам после успешной команды

- `SAS-14` — Источник презентации
- `SAS-15` — Автоматическая инвалидация после commit
- `SAS-16` — Запретить обновление презентации из геймплея и синхронизировать contract

### M5 — RH Cleanup

правила игры — один файл; инфраструктурных Lua-файлов в пакете не остаётся

- `SAS-17` — Слить designer-модули в один файл
- `SAS-18` — Одна команда покупки вместо команды на товар
- `SAS-19` — Удалить инфраструктурные файлы пакета
- `SAS-20` — Перевести экран локации на источник презентации
- `SAS-21` — Удалить `Docs/Authoring/` и синхронизировать документацию
