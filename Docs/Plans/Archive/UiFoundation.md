# UiFoundation: итог выполнения

> **Состояние:** план выполнен; документ является историческим summary, а не источником правил или задач.

## Цель и результат

**Цель:** Довести интерфейс от одного активного экрана и пятнадцати исторически сложившихся виджетов до основания, на котором можно строить экраны игры

**Результат:** базовый набор виджетов с едиными конвейерами, отзывчивая раскладка от 4K до 720p, многослойный документ с реконсиляцией и вкладками, наблюдаемая принадлежность ассетов слою

## Этапы и задачи

### M1 — Identity

повторяемый элемент имеет проверяемую идентичность; реконсиляция получает основание переиспользовать виджет

- `UIF-01` — Принять ADR по основанию UI
- `UIF-02` — Правило ключей в contract
- `UIF-03` — Гейт документа: ключ обязателен и уникален
- `UIF-04` — Вывод ключей в авторском слое
- `UIF-05` — Диагностика переиспользования

### M2 — Scaling Model

интерфейс перестаёт быть кадром, который масштабируют целиком, и становится раскладкой, распределяющей фактический viewport

- `UIF-06` — Два разрешения вместо одного
- `UIF-07` — Отзывчивая раскладка
- `UIF-08` — Политика масштабирования примитива и проверка ресурсом
- `UIF-09` — Кривая масштаба текста и минимальный размер
- `UIF-10` — Матрица разрешений и минимальная цель

### M3 — Core Baseline

из базового набора можно собрать экран сложнее текстового блока с кнопками

- `UIF-11` — Три слоя владения композитами
- `UIF-12` — Контейнер и область прокрутки
- `UIF-13` — Обобщённый список
- `UIF-14` — Контракты данных для существующих виджетов
- `UIF-15` — Модалка и иконка
- `UIF-16` — Соответствие конвейерам

### M4 — Reconciliation

маршрут, оверлеи и модалки существуют одновременно; перестраивается только изменившееся

- `UIF-17` — Слои Game Shell
- `UIF-18` — Конверт документа в Lua
- `UIF-19` — Сопоставление экземпляров и элементов
- `UIF-20` — Правила слоёв
- `UIF-21` — Атомарность и переход `rh` на слои (реальный потребитель — модальное окно подтверждения покупки, отдельный экран `core:screen.modal_confirm`)

### M5 — Tabs

Screen Instance становится рекурсивным; вкладка переключается без участия геймплея

- `UIF-22` — Слой `embedded` в реестре
- `UIF-23` — Схема набора вкладок
- `UIF-24` — Рекурсивный apply
- `UIF-25` — Активная вкладка как UI-local состояние
- `UIF-26` — Интерактивна только активная вкладка

### M6 — Theme Ownership

принадлежность ассета слою наблюдаема и проверяема; перевод не обрезает текст

- `UIF-27` — Каталоги слоёв
- `UIF-28` — Гейт реестра по каталогу слоя
- `UIF-29` — Минимальная тема ядра
- `UIF-30` — Длина текста в локалях
