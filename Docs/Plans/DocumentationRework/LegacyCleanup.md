# M2 — Legacy Cleanup

> **Материализует:** раздел «Принятые решения» [плана](README.md) в части гейта на удалённый API.
> **Задачи:** DOC-05…06.
> **Результат:** инструкция не может ссылаться на механизм, которого нет, — это отклоняется проверкой.

## Результат этапа

Класс дефекта «документация учит удалённому API» перестаёт быть невидимым. Сегодня его не ловит ничто: `Concepts/` и `Guides/` проверяются только на front matter и ссылки.

## Задачи

- [ ] **DOC-05 — Гейт на удалённые идентификаторы**
  - Зависимости: DOC-04.
  - Ключевое ограничение области: **в планах и предложениях упоминание удалённого API законно** — они его удаляют и обязаны называть. Наивный grep по всему `Docs/` дал бы ложные срабатывания там, где документ прав: план RHActorsSimplification обязан называть `validate_amount` и `RESOURCES`, UI-контракты обязаны называть `/Game/...`, потому что запрещают его.
  - Done: гейт проверяет только инструктирующие тиры — `Guides/` и `Concepts/`, где упоминание механизма означает «так делай»; список удалённых и запрещённых идентификаторов ведётся в одном месте вместе с причиной удаления и ссылкой на решение; гейт подключён к CTest наравне с остальными и имеет `--self-test` с отрицательным случаем; добавление нового удалённого механизма расширяет список в том же change set, которым он удаляется.
  - Evidence: `Tools/Documentation/`, `CMakeLists.txt`.

- [ ] **DOC-06 — Чистка legacy-текста**
  - Зависимости: DOC-05.
  - Замерено вне архива: `register_type` — 6 файлов, `/Game/` — 6, `validate_amount` — 5, `RESOURCES` — 4, `actor_decorator` — 2, плюс единичные `type.namespace.path` и `game.data`.
  - Done: каждое упоминание классифицировано как законное (документ запрещает или удаляет механизм) либо как остаток (документ его описывает как рабочий); остатки убраны; гейт DOC-05 проходит; legacy-формы из раздела «Standardization and validation» файла `AGENTS.md` сверены с фактическим состоянием и список обновлён.
  - Evidence: `Docs/Guides/`, `Docs/Concepts/`, `Docs/Architecture/`, `Docs/UI/`.

## Проверка milestone

- [ ] Гейт отклоняет упоминание удалённого API в `Guides/` и `Concepts/`.
- [ ] Гейт не срабатывает на планах, предложениях и контрактах, которые механизм запрещают.
- [ ] Отрицательный случай воспроизводится `--self-test`.
- [ ] В инструктирующих тирах не осталось описаний удалённых механизмов.
