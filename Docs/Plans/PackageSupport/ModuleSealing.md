# M3 — Module Sealing

> **Материализует:** [Lua Runtime Contract § Module loader](../../Architecture/LuaRuntimeContract.md).
> **Задачи:** PKG-10…13.
> **Результат:** таблица экспорта неизменяема после инициализации, а замещаемость модуля объявлена явно.

## Результат этапа

Единственный неконтролируемый путь расширения закрыт: чужую таблицу экспорта нельзя изменить. Каждый модуль ядра явно объявляет, разрешено ли его замещать.

Этап не даёт новой возможности — он готовит почву для M4 и несёт единственный в плане риск регресса на существующем коде, поэтому выполняется отдельным change set и раньше остальных.

## Задачи

- [x] **PKG-10 — Создать ADR по замещению модулей**
  - Реализация меняет семантику загрузчика и уточняет [INV-006](../../Architecture/Invariants.md): замораживаются не только реестры `game`, но и таблицы экспорта модулей.
  - Done: ADR фиксирует замещение как единый механизм замены и расширения, запрет мутации таблиц экспорта, запечатанность по умолчанию и правило «хуки только у победителя»; перечисляет отвергнутые альтернативы (свободный патч, объявленный патч, декораторы по именам функций) с причинами; `LuaRuntimeContract` и `Modding` обновлены синхронно; ADR принят до первой отметки `[x]` в PKG-11.
  - Evidence: [ADR-0025](../../ADR/0025-lua-module-replacement-and-export-freezing.md).

- [x] **PKG-11 — Заморозить таблицы экспорта**
  - Зависимости: PKG-10.
  - Проверено экспериментом: сегодня модуль может подменить функцию в чужой таблице экспорта, в том числе у модуля ядра, и это проходит молча.
  - Done: после возврата таблицы модуля загрузчик ставит метатаблицу с `__newindex`, дающим `LuaModuleExportFrozen`, и `__metatable = false` — тот же приём, что уже применён к `game.repository`; предварительно подтверждено, что ни один текущий модуль не пишет в таблицу экспорта после инициализации; заморозка не мешает использовать таблицу целью `__index`; negative case покрывает и запись нового поля, и подмену существующего.
  - Evidence: `Tests/Lua/lifecycle/module_sealing.lua`, `GV2RuntimeSession.cpp`.

- [x] **PKG-12 — Ввести объявление замещаемости**
  - Зависимости: PKG-10.
  - Done: дескриптор модуля в манифесте принимает `replaceable`; значение по умолчанию — запечатан; ядро размечено — `runtime/`, `boundary/`, `bootstrap/` запечатаны, `gameplay/` и `debug/` замещаемы, `presentation/` и `resources/` запечатаны до появления конкретной потребности; неизвестное значение поля — ошибка манифеста, а не молчаливое `false`.
  - Evidence: `Scripts/bootstrap/manifest.lua`, `GV2RuntimeSession.cpp` (валидация поля `replaceable`).

- [x] **PKG-13 — Синхронизировать contract**
  - Зависимости: PKG-11, PKG-12.
  - Done: `LuaRuntimeContract` описывает неизменяемость таблиц экспорта и объявление замещаемости; [Invariants](../../Architecture/Invariants.md) уточняют INV-006; guide [AddLuaModule](../../Guides/AddLuaModule.md) описывает, что расширение чужого модуля мутацией невозможно и какой механизм придёт на смену в M4.
  - Evidence: `LuaRuntimeContract.md`, `Modding.md`, `Invariants.md`, `AddLuaModule.md`, `ImplementationStatus.md`.

## Проверка milestone

- [x] Запись в чужую таблицу экспорта отвергается типизированной ошибкой.
- [x] Запись в собственную таблицу после инициализации отвергается так же.
- [x] Каждый модуль ядра имеет явное объявление замещаемости; по умолчанию модуль запечатан.
- [x] Полный прогон conformance и Lua-спеков проходит без изменений в существующих модулях.
