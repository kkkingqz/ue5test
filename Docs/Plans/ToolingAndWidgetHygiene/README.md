# План гигиены инструментов и виджетов

> **Материализует:** findings проверки планов — [Plan Audit Findings](../../Status/AuditFindings.md), части, ограниченные одним файлом или одним инструментом.
> **Задачи:** TWH-01…09.
> **Результат:** незащищённые правила получают гейты, два дефекта раскрывающегося списка устранены, пакет-образец перестаёт быть плохим образцом.

## Цель

Устранить findings, каждый из которых **ограничен одним файлом или одним инструментом** и не требует изменений через границы слоёв.

Задачи независимы друг от друга: любую можно взять первой, отказ одной не блокирует остальные. У каждой есть работающий образец рядом — соседний гейт, соседний тест, соседний виджет.

## Отношение ко второму плану

Выполняется **параллельно** с [SceneAndVerificationCorrection](../SceneAndVerificationCorrection/README.md). Планы не пересекаются по файлам, и это правило соблюдается в обе стороны:

| Принадлежит этому плану | Принадлежит соседнему |
|---|---|
| `Tools/`, корневой `CMakeLists.txt` | `Source/GV2/Private/Tests/GV2RuntimeSubsystemTests.cpp` |
| `GV2DropdownSelectWidgetBase.*` | `Source/GV2/Private/Application/GV2ScreenFieldAdapterRegistry.cpp` |
| `GameData/sample/` | `GameData/textsystem/scripts/presentation/` |
| Новые файлы тестов | `Content/TextSystem/UI/Widgets/` |
| `Docs/Plans/README.md` | `Docs/UI/ScreenTemplates.md`, `Docs/UI/SemanticInput.md` |

Правки в общий файл тестов `GV2RuntimeSubsystemTests.cpp` в этот план не входят: новые проверки добавляются **отдельным файлом**.

Единственная зависимость между планами направлена в одну сторону: закрывающая задача соседнего плана ждёт завершения этого.

## Общие правила выполнения

1. Ни одна задача не редактирует файлы, закреплённые за соседним планом (таблица выше).
2. Новая проверка добавляется вместе с **отрицательным случаем**: гейт, который не умеет падать, не считается гейтом.
3. У каждого нового гейта есть образец среди существующих кейсов CTest — форма повторяется, а не изобретается.
4. Закрытый finding снимается из [AuditFindings](../../Status/AuditFindings.md) тем же change set.
5. После каждой задачи: `ctest`, `gv2-headless --self-test`, `--check-scripts`, `validate_docs.py`.

## Итоговый Definition of Done

- [x] Индекс активных планов соответствует содержимому каталога.
- [x] Псевдолокаль проверяется кейсом CTest; удлинённый перевод не обрезается.
- [x] Отклонение контейнерного каталога командой `set` проверяется и описано в contract.
- [x] `main.cpp` защищён структурным правилом вместо числовой границы.
- [x] Гейт констант падает при рассогласовании, а не повторяет их значения.
- [x] Опция раскрывающегося списка не может подменить заголовок.
- [x] Список не закрывается, если его модель не изменилась.
- [x] Пакет `sample` хранит состояние там же, где его хранит игра.
- [x] Один семантический стиль даёт одинаковый физический размер во всех виджетах, и это проверяется.
