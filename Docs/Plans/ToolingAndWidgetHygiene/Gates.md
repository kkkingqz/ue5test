# M1 — Gates

> **Материализует:** findings UIF-AF-01, UIF-AF-03, CCM-AF-01, CCM-AF-02 и рассинхронизацию индекса планов.
> **Задачи:** TWH-01…05.
> **Результат:** правила, которые сегодня держатся на внимательности, начинают держаться на проверке.

## Результат этапа

Каждая задача добавляет один кейс CTest либо приводит документ в соответствие с фактом. Все пять независимы: порядок произвольный.

Общий образец для новых гейтов — существующие кейсы вида `core_boundary_gate_contract` и `core_boundary_gate_negative_contract`: положительный прогон плюс `--self-test`, который обязан упасть на подготовленном нарушении.

## Задачи

- [x] **TWH-01 — Индекс активных планов в соответствие каталогу**
  - `Docs/Plans/README.md` перечисляет один активный план, в каталоге четыре: `ContentEditorHardening`, `CriticalCorrectiveHardening`, `LocationScreen`, `UiFoundationHardening`. Два новых плана добавляются к ним.
  - Done: индекс перечисляет ровно то, что лежит в каталоге; для каждого плана указано, завершён он или выполняется; планы, чей DoD подтверждён, помечены как готовые к архивации — сама архивация выполняется закрывающей задачей соседнего плана и здесь не производится.
  - Evidence: `Docs/Plans/README.md`.

- [ ] **TWH-02 — Псевдолокаль проверяется кейсом CTest**
  - `Tools/Content/generate_pseudolocale.py` реализует удлинение сообщений примерно на 30 % с сохранением токенов формата и не вызывается ни из одного кейса CTest. Из-за этого утверждение «перевод не обрезает текст» не проверяется ничем.
  - Done: добавлен кейс CTest, который генерирует псевдолокаль из существующего каталога и проверяет её корректность — сохранение токенов формата, фактическое удлинение, идемпотентность повторного запуска; псевдолокаль не входит в поставку и не влияет на `repository_content_hash`; добавлен отрицательный случай: каталог с испорченным токеном формата отвергается.
  - Evidence: `Tools/Content/CMakeLists.txt`, `Tools/Content/generate_pseudolocale.py`.

- [ ] **TWH-03 — Вернуть проверку отклонения контейнера для `set`**
  - При переводе негативных CLI-тестов в строгую форму не переехал сценарий `gv2_content_set_rejects_container`. Причина: его команда указывала на корень пакета, а не на контейнер, — тест не проверял того, что заявлял в имени.
  - Фактическое поведение сегодня: `set` на контейнерном каталоге трактует его как пакет без определений и отвечает `definition_not_found` с кодом возврата 2.
  - Done: принято и записано в contract, каким должен быть отказ на контейнерный каталог — отдельный код или существующий `definition_not_found`; поведение закреплено строгим негативным кейсом в той же форме, что соседние: точный код возврата и стабильный diagnostic code за один прогон, без `WILL_FAIL`.
  - Evidence: `Tools/Content/CMakeLists.txt`, `Docs/Architecture/BuildAndTooling.md`.

- [ ] **TWH-04 — Структурный гейт вместо числовой границы `main.cpp`**
  - Граница «< 170 строк» была верна в момент рефакторинга (166 строк) и нарушена уже следующим планом (189), сегодня 222. Гейта нет, поэтому нарушение прошло незамеченным дважды.
  - Функционально файл остаётся роутером: 14 ветвей диспетчеризации, логики построения репозитория, разбора JSON5 и записи файлов в нём нет.
  - Done: числовая граница заменена проверяемым структурным правилом — `main.cpp` не содержит реализации команд, обращений к построению репозитория, разбору JSON5 и записи файлов; правило проверяется кейсом CTest с отрицательным случаем; формулировка правила записана в contract, чтобы следующий план знал, что именно нельзя.
  - Evidence: `Tools/Content/CMakeLists.txt`, `Tools/Content/`, `Docs/Architecture/BuildAndTooling.md`.

- [ ] **TWH-05 — Гейт констант раскладки через инварианты**
  - `GV2.Runtime.UIKit.ScalingModelAndConstants` сверяет `RasterAuthoringWidth` с литералом `3840.0f` и так далее — то есть повторяет заголовок. Тест упадёт только при намеренном изменении константы и ничего не говорит о согласованности значений между собой.
  - Done: сверка с литералами заменена проверкой соотношений — коэффициент перевода растра в единицы раскладки равен отношению соответствующих величин, минимальный поддерживаемый viewport не превосходит единиц раскладки, опорная пропорция выводится из ширины и высоты; тест падает при рассогласованной правке любой одной константы; проверка размещается в **новом файле** тестов, а не в общем `GV2RuntimeSubsystemTests.cpp`.
  - Evidence: `Source/GV2/Private/Tests/`, `Source/GV2/Public/UI/GV2LayoutConstants.h`.
