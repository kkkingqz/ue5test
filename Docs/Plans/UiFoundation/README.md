# План основания UI

> **Материализует:** [Core UI Baseline, Composition and Scaling](../../Proposals/CoreUIBaselineAndScalingProposal.md) и [UI Composition and Scaling](../../Proposals/UiCompositionAndScalingProposal.md).
> **Задачи:** UIF-01…30.
> **Результат:** базовый набор виджетов с едиными конвейерами, отзывчивая раскладка от 4K до 720p, многослойный документ с реконсиляцией и вкладками, наблюдаемая принадлежность ассетов слою.

## Цель

Довести интерфейс от одного активного экрана и пятнадцати исторически сложившихся виджетов до основания, на котором можно строить экраны игры.

План заменяет предыдущий `UiComposition`, который к реализации не приступал. Причина замены — не дополнение, а отмена: модель равномерного масштаба, лежавшая в его основе, отвергнута, и вместе с ней меняется этап масштабирования целиком.

## Состояние на входе

Измерено по репозиторию.

| Что | Сейчас |
|---|---|
| Активный экран | Один; следующий accepted Screen request полностью строит замену |
| Виджеты | 15 `WBP_*`; семь из них не управляются данными |
| Контракты Screen Field | Пять из пятнадцати виджетов |
| Повторяемый контент | Только `ButtonList` |
| Слои, оверлеи, модалки | Описаны в [UI Document](../../UI/UIDocumentAndReconciliation.md), кода нет |
| Реконсиляция по `layer + instance_key` | Описана, не реализована |
| Ключи повторяемых элементов | Одна нормативная строка без правил и проверки |
| Режимы изображения | Три; проверка применимости есть только у `UGV2ImageWidgetBase` |
| Масштабирование, DPI, разрешения | Не описаны ни в одном документе `Docs/UI/` |
| Тема | `Content/UI/Styles/DA_UITheme_Default`; принадлежность слою не зафиксирована |

## Принятые решения

- **Раскладка отзывчивая.** Модель «отрисовать в опорном разрешении и масштабировать кадр» отвергнута: она делает текст на 720p нечитаемым и не даёт увеличить его отдельно.
- **Два разных числа.** Растр рисуется под 3840×2160; размеры в шаблонах выражаются в единицах 1920×1080.
- **Политику масштабирования объявляет примитив, а режим ресурса её проверяет.** Enum `FreeStretch`, `Tile`, `NineSlice`, `PreserveAspect`; несовместимость с режимом ресурса — ошибка до мутации виджета.
- **Текст масштабируется отдельной нелинейной кривой** с минимальным читаемым размером; ниже порога раскладка переносит и прокручивает, а не уменьшает.
- **Минимальная поддерживаемая цель — 1280×720**, критерий «пригоден к использованию», а не «выглядит так же».
- **Слоёв три.** Композит принадлежит `core`, `textsystem` или `rh` по критерию трёх вопросов; переиспользуемость внутри слоя не поднимает его выше.
- **Элемент базового набора вводится вместе с потребителем.** Остальное — в [Core UI Extended Element Set](../../Proposals/CoreUiExtendedElementSetProposal.md).
- **Ключ повторяемого элемента обязателен**, уникален в контейнере и выведен из смысла, а не из позиции.
- **Вкладка — вложенный Screen Instance**, активная вкладка UI-local и в сейв не попадает.

## Границы

Входят: правило идентичности, модель масштабирования, базовый набор с потребителем, многослойная реконсиляция, вкладки, принадлежность ассетов слою.

Не входят:

- **Элементы без потребителя** — `Slider`, `Stepper`, `Toggle`, `ContextMenu`, `Toast`, `GridList`.
- **Фокус, навигация геймпадом и Back** — отдельное [предложение по CommonUI](../../Proposals/CommonUIRuntimeIntegrationProposal.md); здесь закладываются только точки.
- Расширение дайджеста презентации: каноничен экран, всё поверх него UI-local.
- Внешний редактор экранов, портретная ориентация, значения безопасной области.
- Переопределение темы из контентного пакета.

## Критический путь

```text
M1 ─────────────► M4 ──► M5
                   ▲      ▲
M2 ──► M3 ─────────┴──────┘

M6 независим
```

**M1 обязателен для M4:** реконсиляция без правила ключей пересоздаёт все элементы, и дефект при этом не наблюдаем — интерфейс выглядит корректно.

**M2 обязателен для M3:** элемент базового набора обязан объявить политику масштабирования, а объявлять пока нечего.

**M3 и M4 обязательны для M5:** набор вкладок собирается из контейнера и области прокрутки и является вложенным Screen Instance.

## Общие правила выполнения

1. Ассеты редактора (`.uasset`) создаются и меняются только через `unreal-mcp`, с последующим compile, save и проверкой контракта automation-тестом.
2. Ни одна задача не переносит gameplay-авторитет в UE: UI остаётся восстановимой проекцией ([INV-014](../../Architecture/Invariants.md)).
3. Ни одна задача не добавляет partial patch на boundary: Lua отправляет полный документ, diff остаётся внутренним делом Presentation.
4. Ни один новый элемент не заводит собственного пути для текста, изображения или повторяемых детей; проверяется automation по полному инвентарю `/Game/UI`.
5. Ни один элемент базового набора не вводится без потребителя в том же change set.
6. Правила проверяются на **отрицательный** случай.
7. `final_screen_id`, `final_screen_fields`, хэш состояния и `repository_content_hash` в golden меняются только там, где задача сознательно меняет содержимое экрана `rh`.
8. Новое observable behavior синхронно отражается в contract того же change set.

## Итоговый Definition of Done

- [ ] Документ без `key` у повторяемого элемента и с дубликатом ключа отклоняется до apply; изменение порядка не пересоздаёт виджеты.
- [ ] Разрешение авторинга растра и единицы раскладки заданы как два разных значения в одном месте.
- [ ] Раскладка распределяет фактический viewport; равномерное масштабирование кадра нигде не используется.
- [ ] Каждый визуальный примитив объявляет политику масштабирования; отсутствие объявления и несовместимость с режимом ресурса отклоняются.
- [ ] Текст масштабируется отдельной кривой и не опускается ниже минимального читаемого размера.
- [ ] На 1280×720 все обязательные элементы управления доступны, критический текст не потерян, недостижимого контента нет.
- [ ] UI проходит матрицу из шести разрешений, включая две пропорции 21:9.
- [ ] Одинаковый семантический стиль даёт одинаковый физический размер во всех виджетах; одинаковый `resource_id` разрешается одинаково.
- [ ] `Image`, `Portrait` и `Progress` управляются данными через контракты Screen Field.
- [ ] Обобщённый список заменяет частный случай `ButtonList` и подчиняется правилу ключей.
- [ ] Одновременно существуют маршрут, оверлей и модалка; модалка блокирует нижние слои.
- [ ] Ревизия, меняющая одно поле, не пересоздаёт остальные экземпляры и элементы.
- [ ] Переключение вкладки не порождает команду, не меняет ревизию документа и не попадает в сейв; handle неактивной вкладки отклоняется.
- [ ] Класс экрана из namespace пакета вне каталога своего слоя — ошибка валидации реестра.
- [ ] Конфигурация без `textsystem` отрисовывает `core:screen.error`, `core:screen.loading` и `core:screen.recovery`.
