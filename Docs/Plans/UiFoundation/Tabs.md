# M5 — Tabs

> **Материализует:** раздел 5 [UI Composition and Scaling](../../Proposals/UiCompositionAndScalingProposal.md).
> **Задачи:** UIF-22…26.
> **Результат:** Screen Instance становится рекурсивным; вкладка переключается без участия геймплея.

## Результат этапа

Вкладка — вложенный Screen Instance, а не новый вид поля. Переключение не порождает команду, не меняет ревизию документа и не попадает в сейв.

Содержимое всех вкладок присутствует в документе одновременно — прямое следствие UI-local природы активной вкладки. Поэтому интерактивность неактивных вкладок является отдельной задачей.

## Задачи

- [x] **UIF-22 — Слой `embedded` в реестре**
  - Зависимости: UIF-17.
  - Done: запись реестра со слоем `embedded` может быть только вложенным содержимым; попытка использовать её как маршрут, оверлей или модалку — ошибка валидации реестра; обратное ограничение симметрично; набор вкладок внутри набора вкладок отклоняется.
  - Evidence: `Source/GV2/Private/UI/GV2ScreenRegistry.cpp`.

- [x] **UIF-23 — Схема набора вкладок**
  - Зависимости: UIF-22, UIF-12.
  - Done: схема набора вкладок описана в [Screen Templates](../../UI/ScreenTemplates.md) наравне с существующими; значение содержит ключ вкладки по умолчанию и упорядоченный список вкладок с `key`, заголовком в форме `TextSpec`, `screen_id` и полным набором полей; виджет собран из контейнера и области прокрутки базового набора, не создаёт параллельных путей и объявляет политики масштабирования своих примитивов; сырая строка в заголовке отклоняется.
  - Evidence: `Docs/UI/ScreenTemplates.md`, `Content/UI/Widgets/`, `Source/GV2/Private/UI/`.

- [x] **UIF-24 — Рекурсивный apply**
  - Зависимости: UIF-23, UIF-19.
  - Done: адаптер разрешает вложенный `screen_id` через тот же Screen Registry и применяет его поля тем же `ApplyScreenFields`; `node_key_path` удлиняется путём вкладки, binding registry не меняется; реконсиляция вкладок использует правило ключей M1, где `key` вкладки является её `instance_key`; отказ вложенного экземпляра отклоняет документ целиком.
  - Evidence: `Source/GV2/Private/UI/`, `GV2.Runtime.Presentation.*`.

- [x] **UIF-25 — Активная вкладка как UI-local состояние**
  - Зависимости: UIF-24.
  - Done: активная вкладка хранится по паре «путь экземпляра экрана + `field_id`»; начальное значение — ключ по умолчанию, при его отсутствии первая вкладка; реконсиляция, сохраняющая экземпляр, сохраняет активную вкладку; исчезновение активной вкладки возвращает к значению по умолчанию, затем к первой; уничтожение экземпляра теряет состояние; в сейв и в дайджест оно не входит.
  - Evidence: `Source/GV2/Private/UI/`, `GV2.Runtime.Presentation.*`.

- [x] **UIF-26 — Интерактивна только активная вкладка**
  - Зависимости: UIF-25.
  - Done: binding records создаются для всех вкладок, но Semantic Input принимает handle только активной и отклоняет остальные так же, как stale; переключение вкладки меняет множество интерактивных handles, не меняя ревизию документа; правило и его причина записаны в [Semantic Input](../../UI/SemanticInput.md); экран `rh` использует вкладки на реальном содержимом; сохранение и загрузка возвращают маршрут с начальной активной вкладкой.
  - Evidence: `Docs/UI/SemanticInput.md`, `GameData/rh/`, `Tests/Lua/`.

## Проверка milestone

- [x] Переключение вкладки не порождает команду и не меняет ревизию документа.
- [x] Handle неактивной вкладки отклоняется Semantic Input.
- [x] Активная вкладка не попадает в сейв и в дайджест.
- [x] Экран `embedded` не может быть маршрутом; маршрут не может быть содержимым вкладки.
