# M1 — Identity

> **Материализует:** раздел 4 [UI Composition and Scaling](../../Proposals/UiCompositionAndScalingProposal.md).
> **Задачи:** UIF-01…05.
> **Результат:** повторяемый элемент имеет проверяемую идентичность; реконсиляция получает основание переиспользовать виджет.

## Результат этапа

Документ без ключа или с дубликатом отклоняется до apply. Ключи выводятся из сущностей и не требуют участия автора. Наблюдаемое поведение не меняется — меняется то, что о нём можно утверждать.

Этап обязателен для M4: реконсиляция без правила ключей пересоздаёт все элементы, и дефект при этом не наблюдаем.
