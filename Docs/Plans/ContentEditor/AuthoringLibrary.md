# M1 — Authoring Library

> **Материализует:** разделы 3, 3a и 3b [предложения](../../Proposals/ContentEditorPluginProposal.md).
> **Задачи:** CED-01…04.
> **Результат:** операции записи вызываются из библиотеки, а запись становится атомарной.

## Результат этапа

Этап не добавляет ни одного окна. Он снимает препятствие: пока `Json5AstRewriter` и реализации операций заперты внутри исполняемого таргета `gv2-content`, у редактора нет способа их вызвать иначе как подпроцессом.

Побочная выгода не косметическая: атомарность и обнаружение внешних изменений одинаково нужны и CLI, и редактору, и делать их дважды было бы той же ошибкой, что подпроцесс.

## Задачи

- [x] **CED-01 — Принять ADR по слою авторинга контента**
  - Done: ADR фиксирует, что authoritative-реализация авторинга является библиотекой, а CLI и редактор — двумя её frontend-ами; атомарность записи как обязательное свойство операции, а не поведение интерфейса; отклонение записи по устаревшему представлению файла; требование операции пробного применения изменения схемы. Отдельно записывает отвергнутое: подпроцесс CLI в роли backend-а, серия независимых записей как выражение сохранения, оркестрация дублирования на стороне редактора, вторая изменяемая модель контента в редакторе. Номер занимается созданием файла.
  - Evidence: `Docs/ADR/0037-content-authoring-layer.md`, `Docs/ADR/README.md`.

- [x] **CED-02 — Выделить библиотеку авторинга**
  - Зависимости: CED-01.
  - `Json5AstRewriter` и реализации команд лежат в `Tools/Content/Source/`, входящем в исполняемый таргет; чтение при этом уже опирается на библиотеки `GV2ContentCore` и `GV2ContentHostSupport`.
  - Done: операции записи (`new`, `set`, `delete`, `rename`, `duplicate`) и точечная правка JSON5 вынесены в отдельный библиотечный таргет; `gv2-content` становится тонким frontend-ом поверх него и своей реализации операций не содержит; библиотека переносима и не зависит от Unreal; существующие тесты CLI проходят без изменения ожиданий; поведение операций покрыто тестами уровня библиотеки, а не только через CLI.
  - Evidence: `Source/GV2ContentAuthoring/`, `Source/CMakeLists.txt`, `Tools/Content/`, отчёт CTest.

- [x] **CED-03 — Атомарная запись набора полей**
  - Зависимости: CED-02.
  - Сегодня каждая операция перезаписывает файл независимо: отказ на третьем поле оставляет применёнными первые два.
  - Done: библиотека принимает набор изменений одной операцией; запись выполняется по схеме «подготовить результат → провалидировать → заменить файл»; отказ на любом шаге оставляет файл побайтово исходным; дублирование определения реализовано как одна операция, а не как серия записей; комментарии и форматирование сохраняются; отрицательный случай — отказ в середине набора — покрыт тестом, проверяющим неизменность файла.
  - Evidence: `Source/GV2ContentAuthoring/Private/Testing/AuthoringLibraryConformance.cpp`, отчёт CTest.

- [x] **CED-04 — Обнаружение внешнего изменения файла**
  - Зависимости: CED-03.
  - Канонический контент — текстовые файлы под контролем версий; файл может измениться под редактором при `git pull`, ручной правке или работе второго инструмента.
  - Done: операция чтения возвращает признак состояния файла на момент чтения; операция записи принимает его и отклоняет запись типизированной ошибкой, если файл изменился; молчаливая перезапись невозможна; признак не зависит от системного времени и переживает переключение веток; отрицательный случай покрыт тестом.
  - Evidence: `Source/GV2ContentAuthoring/Private/Testing/AuthoringLibraryConformance.cpp`, отчёт CTest.

## Проверка milestone

- [x] Операции записи вызываются из библиотеки; `gv2-content` их не реализует.
- [x] Библиотека не зависит от Unreal.
- [x] Отказ в середине набора изменений оставляет файл исходным.
- [x] Дублирование не может оставить наполовину скопированное определение.
- [x] Запись по устаревшему представлению отклоняется.
