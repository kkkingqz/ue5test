# Заявки на графические и текстовые ресурсы

> **Показывает:** картинки и тексты, которые нужны геймплею `rh` и экранам стартового пакета; документ описывает потребность и не вводит новых правил.

Ресурсы в сессиях разработки геймплея не создаются: код и данные ссылаются на ID, за которым пока стоит заглушка. Текст — Definition `text` с `source_message: "[<id>]"`, картинка — Definition `resource` с `required: false` и без файла. Здесь записано, что должно оказаться за каждым ID.

Количество, которое зависит от контента, задаёт дизайнер вместе со входом задач [RHStartPackage](../Plans/RHStartPackage/README.md#входные-данные-от-дизайнера); задача, получившая вход, уточняет здесь конкретные ID. ID следуют [RH Gameplay Architecture § 4.4](../RH/GameplayArchitecture.md#44-соглашения-об-id).

## Общие требования

- Картинки — `texture_2d`. Иллюстрации, портреты и иконки используют режим `fixed_aspect`: соотношение сторон задаёт блок экрана, и оно входит в смысл ID — смена соотношения требует нового ID ([Image Resources](../UI/ImageResources.md)). Фоны динамического размера — `tile`, рамки и панели — `nine_slice`.
- Раскладка задаётся в единицах 1920 × 1080, а экраны проверяются до 3840 × 2160; разрешение исходника должно выдерживать размер блока на 4K.
- Язык текстов — русский (`localization/ru.po`). Параметры записываются в фигурных скобках: `{gold}`. Подстановка локализуемого имени в параметр ждёт [GAP-011](EngineGaps.md#gap-011-локализуемые-аргументы-textspec); до этого имя показывается отдельным полем экрана.
- Системные заглушки уже есть и новых не требуется: `textsystem:resource.ui.missing_background`, `missing_character`, `missing_portrait`, `missing_icon`. Если необязательная картинка шага диалога или записи отчёта отсутствует, блок показывается без картинки, а не с заглушкой.

## RR-001. Графика контента `rh`

| Ресурс | ID | Количество | Где показывается | Требования |
|---|---|---|---|---|
| Фон локации | `rh:resource.location.<группа>.<имя>.background` | 10 | сцена экрана локации | `fixed_aspect` по блоку сцены `WBP_LocationScreen`; без персонажей на картинке — их показывает сцена отдельно |
| Вариант фона локации | `rh:resource.location.<группа>.<имя>.background_<вариант>` | по данным локаций | сцена экрана локации | как у фона; только если дизайн задаёт варианты по условиям |
| Портрет игрока | `rh:resource.actor.player.portrait` | 1 | панель статуса | `fixed_aspect` по блоку портрета |
| Портрет уникального NPC | `rh:resource.actor.<группа>.<имя>.portrait` | по числу уникальных NPC | диалог, магазин (портрет торговца), сцена танца | `fixed_aspect` по блоку портрета; один и тот же портрет на всех экранах |
| Фигура NPC на сцене локации | `rh:resource.actor.<группа>.<имя>.scene` | по числу NPC, видимых на локациях | сцена экрана локации, поле `characters` | прозрачный фон, привязка к нижнему краю |
| Портреты типовых NPC | `rh:resource.actor.<шаблон>.portrait_<n>` | набор на каждый шаблон | диалог, сцена танца | как у портрета уникального NPC; генерация выбирает из набора |
| Фигуры типовых NPC на сцене | `rh:resource.actor.<шаблон>.scene_<n>` | набор на шаблон, парный портретам | сцена экрана локации | как у фигуры уникального NPC |
| Иконка предмета | `rh:resource.item.<группа>.<имя>.icon` | по числу предметов | магазин, панель статуса | `fixed_aspect` по блоку иконки |
| Картинка шага диалога | `rh:resource.dialogue.<группа>.<имя>.<шаг>` | необязательна, по данным диалогов | экран диалога | `fixed_aspect` по блоку картинки; покрывает и диалоги исходов продажи, и реакции на переход |
| Картинка записи отчёта о ходе | `rh:resource.turn_phase.<имя>.<исход>` | необязательна, по фазам | экран отчёта о ходе | `fixed_aspect` по блоку картинки записи |
| Картинка сцены танца | `rh:resource.dance.<имя>.scene` | по числу танцев | экран сцены с участниками | `fixed_aspect` по блоку картинки сцены |

Отдельные картинки торговца, исходов продажи и реакций на переход не нужны: торговец — это портрет NPC, а исходы и реакции показываются диалогом.

## RR-002. Тексты контента `rh`

| Текст | ID | Количество | Параметры | Где показывается |
|---|---|---|---|---|
| Название локации | `rh:text.location.<группа>.<имя>.title` | 10 | — | верхняя панель, кнопка перехода |
| Описание локации | `rh:text.location.<группа>.<имя>.description` | 10 и варианты по условиям | — | экран локации |
| Подпись взаимодействия | `rh:text.interaction.<группа>.<имя>.title` | по числу взаимодействий | по данным, например `{cost}` | меню локации |
| Имя игрока и уникального NPC | `rh:text.actor.<группа>.<имя>.name` | 1 + число уникальных NPC | — | панель статуса, диалог, магазин, сцена танца |
| Набор имён типового NPC | `rh:text.actor.<шаблон>.name_<n>` | набор на каждый шаблон | — | диалог, сцена танца |
| Название характеристики | `rh:text.stat.<имя>` | по набору характеристик | — | панели, сцена танца |
| День | `rh:text.status.day` | 1 | `{day}` | верхняя панель |
| Время суток | `rh:text.status.time.<период>` | 4 при ходе в 6 часов | — | верхняя панель |
| Основной ресурс | `rh:text.status.gold` | 1 | `{gold}` | верхняя панель |
| Полоска выносливости | `rh:text.status.stamina` | 1 | `{current}`, `{max}` | панель статуса |
| Завершить ход | `rh:text.turn.end` | 1 | — | меню локации |
| Заголовок отчёта о ходе | `rh:text.turn_report.title` | 1 или по исходам | — | экран отчёта |
| Запись отчёта | `rh:text.turn_phase.<имя>.<исход>` | по фазам и исходам; минимум — восстановление выносливости | по фазе, например `{amount}` | экран отчёта |
| Продолжить | `rh:text.turn_report.continue` | 1 | — | последняя запись отчёта |
| Название и реплика магазина | `rh:text.shop.<имя>.title`, `.description` | по числу магазинов | — | экран магазина |
| Баланс | `rh:text.shop.balance` | 1 | `{gold}` | экран магазина |
| Цена | `rh:text.shop.price` | 1 | `{price}` | экран магазина |
| Купить, Уйти | `rh:text.shop.buy`, `rh:text.shop.leave` | 2 | — | экран магазина |
| Название и описание предмета | `rh:text.item.<группа>.<имя>.name`, `.description` | по числу предметов | — | магазин, панель статуса |
| Реплика шага диалога | `rh:text.dialogue.<группа>.<имя>.<шаг>.text` | по данным диалогов | по данным | экран диалога |
| Вариант ответа | `rh:text.dialogue.<группа>.<имя>.<шаг>.choice.<вариант>` | по данным диалогов | — | экран диалога |
| Далее в диалоге | `rh:text.dialogue.next` | 1 | — | вариант «Далее» |
| Диалоги исходов продажи | как реплики диалога | по исходам и «нечего продать» | по данным, например `{price}` | экран диалога |
| Диалоги реакций на переход | как реплики диалога | по реакциям | по данным | экран диалога |
| Название танца | `rh:text.dance.<имя>.title` | по числу танцев | — | экран сцены |
| Временная характеристика сцены | `rh:text.dance.<имя>.meter.<характеристика>` | по правилам танца | `{value}` | полоски участников |
| Движение | `rh:text.dance.<имя>.move.<движение>` | по правилам танца | — | кнопки сцены |
| Описание момента и итога танца | `rh:text.dance.<имя>.moment.<момент>` | по правилам танца | по данным | экран сцены |
| Завершить танец | `rh:text.dance.finish` | 1 | — | экран сцены |

## RR-003. Причины отказа и недоступности `rh`

Каждая причина — пара error `rh:error.<механика>.<причина>` и текст `rh:text.error.<механика>.<причина>`. Текст показывается подсказкой у неактивного пункта и при отказе команды.

| Причина | ID текста | Параметры |
|---|---|---|
| Не хватает выносливости | `rh:text.error.interaction.no_stamina` | `{required}`, `{current}` |
| Локации не связаны | `rh:text.error.travel.not_connected` | — |
| Не хватает золота | `rh:text.error.shop.not_enough_gold` | `{price}`, `{gold}` |
| Предмета нет в ассортименте | `rh:text.error.shop.not_in_assortment` | — |
| Уже идёт другое взаимодействие | `rh:text.error.mode.busy` | — |
| Нет нужного предмета | `rh:text.error.condition.has_item` | имя предмета ждёт GAP-011 |
| Условие флага не выполнено | `rh:text.error.condition.flag` | — |
| Движение танца недоступно | `rh:text.error.dance.<причина>` | по правилам танца |

Список растёт вместе со словарём условий: каждый новый тип условия добавляет свою причину.

## RR-004. Шаблоны экранов `textsystem` и `core`

| Ресурс | Владелец | Где | Примечание |
|---|---|---|---|
| Подпись «Далее» пошагового просмотра | владелец элемента по решению SPS-01 (`core` или `textsystem`) | экран отчёта о ходе | текст шаблона, не значение из Lua |
| Тексты отказов механизма режимов | `core`: `core:text.error.mode.already_active`, `core:text.error.mode.not_active` | отказ команды | `rh` проверяет режим заранее, поэтому игрок обычно их не видит |
| Стиль неактивной кнопки | тема `DA_UITheme_Default` (`textsystem`) | все элементы действия | CommonUI-состояние `disabled` |
| Рамка подсказки | тема; владелец элемента по решению SPS-01 | подсказка у неактивного элемента | `nine_slice` |
| Оформление экранов отчёта, магазина, диалога и сцены | тема (`textsystem`) | новые экраны | `nine_slice` для панелей, `tile` для фона; можно собрать на существующих стилях |
