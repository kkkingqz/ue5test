# Добавить событие и реакцию

> **Задача:** опубликовать факт о произошедшем изменении и обработать его в другом модуле.
> **Нужно:** команда, из которой факт публикуется — [AddCommand](AddCommand.md).
> **Нормативно:** [Commands and Events](../Architecture/CommandsAndEvents.md).

## Шаги

**1. Выбрать `event_id`.** Kind `event`, имя описывает свершившийся факт: `core:event.location.enter`, `core:event.shop.purchased`. Не `gold_changed` — это описание записи в поле, а не игрового факта.

**2. Публиковать из команды.** Факт накапливается в контексте текущей команды и доставляется после успешного commit. Отказавшая команда не публикует ничего.

**3. Подписаться.** Подписка регистрируется на фазе `register` по `event_id` и замораживается вместе с остальными реестрами:

```lua
game.events.subscribers.register(
    "core:subscriber.quest.on_enter",
    "core:event.location.enter",
    function(event)
        if event.payload.to_location_id ~= "core:location.city.tavern" then
            return
        end
        -- реакция
    end)
```

**4. Проверять условие внутри обработчика.** Фильтров в API подписки нет: «сработать только на переход в таверну» — это `if` в обработчике, а не параметр подписки.

**5. Добавить спеку.** Полезные кейсы: порядок фактов, отсутствие публикации при отказе команды, несрабатывание подписчика на чужое условие.

## Что обработчику можно и нельзя

Можно: читать состояние и репозиторий, опубликовать ещё одно событие, поставить команду в очередь.

Нельзя: менять состояние напрямую — во время доставки mutation window закрыт. Отложенная команда выполнится после завершения текущей доставки и откроет собственное окно.

Ошибка в обработчике прекращает текущую доставку, оставшиеся события отбрасываются, сессия переходит в `Failed`, но исходная команда остаётся зафиксированной.

## Типичные ошибки

**Событие как вопрос.** «Можно ли купить» — это валидатор. Событие сообщает, что покупка уже состоялась, и отменить её нельзя.

**Ожидание фильтрации в подписке.** Её нет намеренно; см. решение в архивном плане [GameplayEventsAndWorld](../Plans/Archive/GameplayEventsAndWorld/README.md).

**Мутация из обработчика.** Отклоняется типизированной ошибкой.

**Расчёт на порядок регистрации модулей в файловой системе.** Порядок подписчиков определяется приоритетом, порядком загрузки пакета и порядком регистрации — не именами файлов.
