# Отклонённые предложения

Здесь хранятся предложения со статусом `proposal_state: rejected` — рассмотренные и отклонённые направления.

Отклонённое предложение сохраняется, а не удаляется, потому что причина отказа является таким же результатом размышления, как и принятое решение. Без неё тот же вопрос возвращается через несколько месяцев, и разбор повторяется с нуля — включая аргументы, которые уже были признаны неубедительными.

Обязательное требование к документу здесь: **причина отказа записана в самом документе**, а не только в истории обсуждения. Отдельный раздел объясняет, что именно предлагалось, почему это отклонено и при каких условиях вопрос имеет смысл открыть заново. Отклонение «пока рано» и отклонение «направление неверно» — разные вещи, и различие должно быть видно из текста.

Отклонённое предложение не является нормативным и не источник задач.
